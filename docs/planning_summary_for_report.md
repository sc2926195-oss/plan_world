# WAM-V 入港走廊规划 —— 阶段进展汇报

## 1. 任务定义与边界

- **目标**：在 `plan_world`（100 m × 100 m 开放水域，北侧 y=100 布置 3 座 U 形浮动泊位）中，面对每次随机生成的 10 个静态漂浮障碍，为 WAM-V 离线生成 **3 条“从起点 (50,0) 分别前往三个港口”的可行入港走廊**（路径 + 走廊）。
- **走廊含义**：比船略宽（默认半宽 1.5 m，总宽 3.0 m；船半宽约 1.25 m，泊位内净宽 5 m），保证船**理论上可沿走廊直线入港、船头朝北、不碰障碍与码头**。
- **阶段边界**：目前**只做规划、不做运动控制**；走廊作为后续交给控制组/演示的“几何约束通道”。
- **仿真复用**：VRX + Gazebo(gz-sim7/Garden) + ROS 2 Humble。新世界 `my_plan_world` 与 scan/port 世界平级，复用 WAM-V、波浪、港口（按 scan 风格定制为 5 m×7 m 内净空 U 形泊位）等仿真资源。

## 2. 场景与输入建模

- 布局：泊位中心 (0,100)、(50,100)、(100,100)，开口朝南面向水域；船在 (50,0)，初始朝北（正对中间港）。
- 障碍：10 个静态漂浮障碍（正三角形或正方形，占地约 10 m²、高 0.6 m），**每次启动随机生成**，同时写入世界文件 SDF 与真值文件 `obstacles_meta.json`（含世界系多边形），规划直接读真值，不在仿真内“感知”。
- 一致性：启动、规划、出图、Gazebo 显示全程使用**同一随机种子**，保证“仿真里的障碍 = 规划用的图 = 显示的走廊”。

## 3. 规划方法（管线）

总体采用 **“路径搜索 → 平滑 → 走廊 → 校验”** 的分层结构，理由：

1. **为什么不用网格 A\***：100×100 的 1 m 网格（1 万节点）对搜索本身不是瓶颈，但**离散分辨率会抹掉 5 m 宽泊位口、贴障碍转弯**等细节；连续空间的采样法更合适，故采用 **Informed RRT***。
2. **走廊安全性的等效处理**：走廊 = 中心线 ± 半宽。规划时把障碍（及码头区域）按“走廊半宽 + 安全裕度”膨胀，只要中心线避开膨胀障碍，走廊就自动无碰撞，校验量小。
3. **运动学判断**：WAM-V 是双推进器差速船，**可原地转向**，不存在硬性最小转弯半径约束，因此不引入 Dubins 类方法，曲率只作软性上限；但对“入港”要求**末段笔直、船头正**。

各阶段：

| 阶段 | 做法 |
|---|---|
| 1. 路径搜索 | Informed RRT*：先普通 RRT* 得首条解，再压缩到以起终点为焦点的椭圆内采样优化；障碍按 clearance=半宽+裕度 膨胀，码头整体视为不可进入区域 |
| 2. 简化 | 贪心视线 shortcut，去掉冗余转折点 |
| 3. 入港直线段 | 从对接点 (px,90) 沿泊位轴线**笔直**插入港中心 (px,100)，从几何上保证“船头正入港、与墙体留隙” |
| 4. 平滑 | 三次 B 样条（候选：轻微平滑 / 严格插值 shortcut / 严格插值加密折线），选“曲率最小且长度接近最短”者；y≥92 后渐进拉直到轴线，末端航向精确 90° |
| 5. 走廊生成 | 中心线 ± 走廊半宽 → 左右边界（走廊多边形） |
| 6. 校验与重试 | 中心线到障碍与码头墙体距离 ≥ 半宽；校验不过或转弯过尖（半径<1 m）则换随机种子重试（最多 6 次） |
| 7. 输出 | `planner_output.json/.csv`（中心线/走廊边界/航路点/曲率/最近距离）+ 三条航道同图 PNG + Gazebo 动态显示（纯视觉静态模型，服务器端注入，可逐条显示/清除/依次展示） |

## 4. 当前效果（示例随机布局，障碍 seed = 940194097，走廊半宽 1.5 m）

| 航道 | 长度 (m) | 最大曲率 (1/m) | 等效最小转弯半径 (m) | 离障碍最近 (m) | 离码头墙最近 (m) |
|---|---|---|---|---|---|
| port_0 (x=0) | 125.6 | 0.71 | 1.4 | 3.65 | 2.50 |
| port_50 (x=50) | 104.3 | 0.42 | 2.4 | 4.83 | 2.50 |
| port_100 (x=100) | 117.5 | 0.67 | 1.5 | 3.68 | 2.50 |

- 三条航道全部通过校验：中心线离障碍/码头墙均 ≥ 1.5 m（走廊半宽）；入港段贴泊位轴线、末端航向 90°。
- 已在多组不同随机障碍布局上验证，均能成功规划（个别布局会因障碍逼迫产生较小转弯半径，差速船可接受；若需更平缓可调大安全裕度/入港点参数）。
- 说明：最大曲率出现在“开放水域转向进入入港直线段”附近，半径可小到约 1.4 m；由于差速船可原地转向，不作为硬约束，后续如需硬性限制可加曲率约束。

## 5. 关键参数（均可调）

| 参数 | 当前值 | 含义 |
|---|---|---|
| 走廊半宽 hw | 1.5 m | 走廊总宽 3.0 m；泊位内净宽 5 m，故 hw 需 < 2.5 m |
| 搜索安全裕度 margin | 2.0 m | 中心线相对障碍的实际避障距离 = hw + margin |
| 入港直线起点 y | 90 m | 从该处起笔直入港（港中心 y=100，泊位口 y≈96.5） |
| B 样条平滑因子 | 自适应 | 轻微平滑优先，校验不过则降级 |
| 尝试次数 | 6 | 校验失败/过尖时换随机种子重试 |

## 6. 局限与下一步

1. **时间/速度剖面缺失**：目前输出的是几何走廊，不含“何时以多快走”。若控制组需要可直接执行的轨迹，可在走廊约束内做**分段多项式 / min-jerk 轨迹优化**（带时间分配与速度、曲率限制），B 样条方案可平滑升级过去。
2. **曲率仅软约束**：如需硬性最小转弯半径，可加曲率上界约束或改用带曲率限制的平滑。
3. **静态障碍**：当前障碍静态；后续可扩展动态障碍、水流/风场影响。
4. **参数标定**：走廊宽度、平滑度将结合实际船宽与视觉效果继续标定。
5. **工具链已就绪**：一键脚本（随机障碍→规划→出图→开仿真）、三航道同图、JSON/CSV 数据、Gazebo 逐条动态显示，便于向控制组交接与复现。
