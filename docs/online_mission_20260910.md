# 在线任务（去作弊版）— 2026-09-10

## 目标
船只知道：**自身位姿（真值）+ 三个港口位置**；
障碍物位置、哪条走廊、哪个港口正确 全部靠 **lidar + 相机在线获取**。
流程：巡航 → lidar 感知障碍 → 栅格 A* 在线避障 → 到港口检查点判色 → 绿港进港。

## 实现
- `control/lidar_circles.py`：lidar 点云(近水平环) → 空间聚类 → 圆拟合 → 障碍圆。
  去噪：水域范围/距船>4m/高度过滤 + 形状过滤(细长=墙) + 港口区剔除 +
  ≥3 帧命中 + 25s 过期 + 上限 12 个。
- `control/online_mission.py`：
  - 感知线程维护"已感知障碍圆"地图；
  - 栅格 A*（感知圆 + 已知码头墙膨胀）规划；**滞回重规划**（路径被挡 或 每 6s）；
  - 路径 shortcut + 等距重采样；小艇纯跟踪控制（基推 18N、增益 15、转向阻尼、steer-sign=-1）；
  - 到检查点(距港口中心 26m) → 原地转向正对港口 → 相机判色（只统计画面中央区，
    采 ~6s 比较红/绿闪烁差幅）→ 绿港则低速进港。
  - Gazebo 可视化：`online_path`(青色小球=实时规划路径) + `online_obstacles`(红圈=感知障碍)。

## 2026-09-10 追加改造
1. **绿港随种子随机(可复现)**：`generate_obstacles.py --seed N` 同时决定障碍布局与
   哪个港口是绿港（`field_assets/set_beacons.py --seed N` / `green_for_seed()`）。
   例：seed=100 → port_2 绿；seed=1 → port_0 绿。
2. **拜访顺序默认 0→1→2**（从 (50,0) 出发的最短扫掠，约 189m；1→0→2 约 224m）。
3. **停船安全**：`stop_all()` + SIGINT/SIGTERM 处理 + `finally` 兜底；
   新增 `control/reset_boat.py`（先清零推力→复位→再清零），避免"只复位不停船"导致
   船带着残留推力自己跑。
4. **判色更稳**：统计区放宽到画面 20%~80% x 5%~80%、采样 ~7s；
   若红/绿都测不到 → 判 `unknown`，靠近 6m 再试一次（不再把"没看到"当红灯）。
5. **入港末段 final_dock()**：先摆正到 +Y 艏向，再小推力直进并做横向对中，
   到泊位内目标 y 停车（比通用跟踪器斜着蹭进去更稳）。
