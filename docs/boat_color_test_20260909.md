# 小船(boat_real) 相机颜色感知测试 — 2026-09-09

环境: plan_world + boat_real(1.2x0.85m 小船), 新增前视相机
`front_camera_sensor`(1280x720 RGB@30Hz, HFOV~80°, 装在桅杆 ~0.44m 高,
俯角 15°, 与旧 WAM-V 相机同参数)。port_1 绿信标(3s亮/2s灭), port_0/2 红。

测试脚本: `control/boat_color_test.py`（正对距离扫描 + 20m 偏航扫描）

注意: 若统计全图, 码头的固定红/绿角杆会产生大量“常量”像素; 船的漂浮
晃动又会让杆子边缘进出画面, 制造假 toggle。因此判色要用**灯区/闪烁源**
而不是全屏像素和。

## 结论(给后面程序)
1. 小船能检测颜色。正对: 可靠判色 ≤ ~30-40 m; 40-60 m 变弱; >~60 m 不可靠。
   与旧 WAM-V 相当(信标灯高 2.15m, 相机低并不明显缩短距离)。
2. 船头偏 ≤~45°(灯仍在相机 HFOV~±40°)仍可辨。
3. 红/绿区分在 ~28-30m 内做“闪烁源颜色比较”是可靠的; 建议接近到 ≤30m
   再最终判色, 与旧结论一致。
4. 实践策略: 规划走廊把船带到目标港 30m 内大致对准 → 相机判红/绿确认 →
   再入港。40m+ 只作“疑似方向”提示, 需要时域多帧累加。
