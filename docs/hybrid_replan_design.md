# 混合避障寻路设计（全局 RRT* + 局部栅格 A*）— 2026-09-10

## 场景（用户确认）
- 已知：自身位姿（仿真先用 /world/plan_world/pose/info 真值）、三个港口位置、船运动模型。
- 未知：障碍物位置（每次随机）、哪个港口正确（需相机判色，≤~30m 可靠）。
- 成功：固定顺序拜访候选港 → 识别绿港 → 入港停稳。

## 三段式闭环
1. **巡航/探测**：用全局 RRT*+B样条走廊从当前点走到目标港前检查点（~25–30m）。
2. **反应/重规划**：lidar 近水平环（ring 7..10）→ 圆弧拟合 → 圆障碍；
   若圆侵入当前走廊（中心线到圆面 < hw+margin），在障碍附近开局部窗口，
   栅格 A* 绕行 → B样条拼接 → 校验（净距/R_min/港墙）→ 替换被挡段。
3. **判色/入港**：到检查点判红绿；绿港走原有斜入港走廊，低速停稳。

## 为什么用混合结构
- RRT*：连续空间、全局质量好、曲率可控（已有入港逻辑）。
- 栅格 A*：局部反应场景**确定性**、易调、易验收；100×100m@1m=1万格/0.5m=4万格，
  单次搜索 <10ms，算力不是问题；真正要解决的是“路径质量”，交给 B样条+曲率校验。
- D*/D* Lite 在此规模没必要，每次重跑 A* 即可。

## 新增文件
- `planner/occ_grid.py`：圆障碍 → 占据栅格（blocked + soft 代价）→ 8连通 A*（禁切角）。
- `planner/replan.py`：被挡检测 / 局部窗口 / A* / B样条拼接 / 校验 / 出图 / JSON。

- `planner/replan_output.json`：绕行中心线、走廊边界、指标（供后续可视化/闭环使用）。
