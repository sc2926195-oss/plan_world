# 方案 1 设计说明：姿态空间的有界曲率 RRT
## Unified Pose-Space Bounded-Curvature RRT (kinodynamic-lite RRT)

> 目的：根治“开阔 RRT（只认二维点）与入港库（认带朝向状态）不适配”的问题。
> 思路：去掉“两段式 + 事后匹配”，改成**一个带姿态(航向)的搜索问题**，
> 入港形状由搜索自然产生。本文件只做设计与技术说明，供学习与评审。

---

## 0. 问题回顾：不适配在哪里

现状（两段式）：
```
2D RRT  → (px,90) 点，无航向概念
  ↓ 事后
入港库(需要 位置+航向θ)  → 匹配失败就重试/失败
```

矛盾点：
- RRT 的状态是 (x,y)，不携带航向；
- 入港库的“条目”本质是**姿态级**的：它要求船在某处以某个 θ 进入；
- 于是只能靠“路径末端方向 vs 库条目方向”的**事后猜测+碰运气**。
- 我们的船是差速驱动：开阔水域里能原地转，但上级要求尽量不停车 → 转弯必须展开成半径 ≥ R_min 的弧。这个“有界曲率 + 最终姿态”的约束其实**应该在搜索内部**，而不是事后接。

**结论**：把状态升级成 (x, y, θ)，把“半径 ≥ R_min 的直行/圆弧”作为搜索的基本运动，把“港内目标姿态”作为搜索终点——这就是本方案。

---

## 1. 核心概念

### 1.1 状态空间 Configuration Space
- 状态：`q = (x, y, θ)`
  - (x,y)：水面平面位置（ENU，m）；
  - θ：船头航向（rad，`atan2` 约定，正北 = π/2）。
- 起点状态：`q_start = (50, 0, π/2)`（出生点朝北）。
- 目标状态：`q_goal = (px, 100, π/2)`（三个港口各自 x，笔直停靠、船头朝北）。
  - 实际用**目标区域 + 容差**（位置误差 ≤ ~0.5~1 m，航向误差 ≤ ~5~10°），或最后用 Dubins 精确连接到 q_goal。

### 1.2 有界曲率与运动原语
- 差速船前向运动：可看作“沿当前航向直行，或按角速度转”，曲率
  `κ = 1/R`，最小转弯半径约束：`R ≥ R_min`，即 `κ ≤ κ_max = 1/R_min`。
- 因此**基本运动 = 直行（R=∞）或半径为 R∈[R_min,∞) 的左/右圆弧**。
  - 不允许原地转（R=0）：正好符合“不刹车不停车”的要求；
  - 不需要倒车 → 不需要 Reeds-Shepp，只有“前向 Dubins 型”运动。

### 1.3 为什么这样能“长出”入港形状
在终点姿态 `(px,100,90°)` 和港墙约束下，搜索自然只会接受“能一路开进港且最后朝北”的树：
- 开阔水域：绕障碍、用大半径弧；
- 接近港时：被 `R_min` 与墙体共同约束，必须提前转好、以接近正北的姿态穿过口部；
- 港内 5 m 宽 × 7 m 深：只有“基本直行”的弧（R 很大）放得下 → 末段自然变成“贴轴直行到中心”。
入港形状是约束的**解**，不是预制的条目。

## 2. 算法设计

### 2.1 总体结构（伪代码）
```
Tree ← {q_start}
for iter = 1..N:
    q_sample ← Sample()            # 见 2.3
    q_near  ← Nearest(Tree, q_sample)     # 状态距离(带航向的度量)
    q_new   ← Steer(q_near, q_sample)     # 有界曲率扩展，见 2.2
    if q_new exists and CollisionFree(q_near→q_new):   # 见 2.4
        Tree.add(q_new)
        # (可选)RRT* 重连：对近邻用 Dubins 型连接，代价=弧长
    if ReachGoal(q_new, q_goal):           # 见 2.5
        path ← TraceBack(q_new)
        return path
return failure (或转回退/提高迭代)
```

### 2.2 Steer：有界曲率扩展（本方案的关键）
从 `q=(x,y,θ)` 向采样点 `p=(xp,yp)` 扩展，要求：
- 只能直行或半径 ≥ R_min 的圆弧；
- 不倒退（前向）；
- 单调逼近（避免原地绕圈）。

**做法（单圆弧法，够用且简单）**：
1. 计算采样点相对当前位置的方位角 `φ=atan2(yp-y, xp-x)`；
2. 航向误差 `Δθ = wrap(φ − θ)`；若 |Δθ| 很大（例如 >~90°），该采样方向对当前状态不可直接逼近 → 本轮拒绝该采样（这会让扩展成功率下降，但保证每条边合法；用更多迭代/更好的采样来弥补）；
3. 求**过 q 且经过 p 的圆弧半径**（几何上过两点、且起点切向 = θ 的圆有两个解）：
   `r = chord / (2·sinΔθ)` 类公式（须考虑两侧转向），若 `r ≥ R_min` → 可用；
4. 沿该圆弧前进 `L = min(弧长, step_max)`，得到新状态 q_new（位置+新航向 θ_new）；
5. 若找不到满足 R_min 的弧（p 太近/方向太偏）→ 返回 None（合法拒绝）。

> 说明：为了更好绕障碍，也可在步骤 3 前“随机选一个转向半径 r∈[R_min, r_max] 左/右”，并沿该弧前进固定步长；两者可结合（采样点引导 + 随机弧扰动）。

### 2.3 采样 Sample
- 开阔处：在 (x,y) 均匀采样 + θ 均匀（或 θ 只在与采样方向一致的 ± 锥内采样，提高效率）；
- **目标偏置**：以概率 p_goal 直接采 `q_goal`（可带小噪声），保证树向港内生长；
- **港前引导(可选提速)**：在靠近某港口的“口部走廊”(mouth funnel) 内，按“接近正北的航向”采样，帮助树钻进口部（这是性能优化，不改变正确性）；
- Informed（可选）：首解后把位置采样压缩到椭圆内，θ 向终点方向采样。

### 2.4 碰撞与层
- 沿用“分层 clearance”：
  - 开阔障碍：中心线离障碍 ≥ hw（走廊半宽；不再需要为“样条过冲”留大裕度，因为路径本身就是可执行几何；可保留少量缓冲 ε≈0.3~0.5 m）；
  - 其它港口：整座禁区；
  - 目标港：只挡墙体，港内 clearance 取 hw + 贴墙余量（如 0.5 m）。
- 直线段：离散采样点判距；**圆弧段：按弧长步长(≈0.25 m)采样判距**（点安全 ⇔ 走廊管安全，前提是 corridor=中心线±hw）。

### 2.5 终点判定与精确连接
- 若新节点进入目标容差区（位置 ≤ r_goal≈1 m、航向差 ≤ Δθ_goal≈10°），可停止；
- 更优：尝试用 **Dubins 最短曲线（前向、R≥R_min）**把该节点精确连到 q_goal，若连线无碰撞且长度合理 → 采纳，得到“精确到终点姿态”的路径。
- 这样终点姿态是**精确满足**的，而不是“差不多”。

### 2.6 状态度量（Nearest/Rewire）
- 位置欧氏距离 + 航向加权：
  `d(q1,q2) = √((Δx)²+(Δy)²) + w·|wrap(θ1−θ2)|`，w 取几米（把 1 rad ≈ 若干米）。
- RRT* 重连：对半径内近邻尝试 Dubins 型连接，若无碰撞且 `cost(q_old) > cost(q_new)+connect_cost` 则重连。

## 3. 硬约束与校验（全部在搜索内完成）

| 约束 | 如何保证 |
|---|---|
| 曲率 ≤ 1/R_min | 每条边由构造保证（直行或 R≥R_min 弧） |
| 不原地转/不倒退 | 运动原语只含前向直行与 R≥R_min 弧 |
| 离障碍 ≥ hw(+ε) | 分层碰撞检查，直线/弧都采样判定 |
| 离港墙 ≥ hw(+贴墙余量) | 港内墙体层 |
| 终点姿态 | 目标姿态容差或 Dubins 精确连接 |
| 全程不刹车可跟随 | 路径任意点曲率有界；未来再叠加速度剖面 |

**输出**：primitive 序列（每段 type=straight/arc, radius, 起点位姿、终点位姿）+ 稠密中心线采样 + 走廊 ±hw + 曲率/内缘半径/口部状态报告。不需要事后 B 样条“圆角”（可选做轻微装饰）。

## 4. 与相关方法的联系（供学习）

- **Dubins 曲线**：两点间前向最短、有界曲率曲线（6 种词法）。我们的 steer/精确连接可用其子集；
- **RRT / RRT\***：采样树；本方案 = 给 RRT 换上“有界曲率 steer”，属于 **kinodynamic RRT** 的“lite”版（忽略时间/速度，只约束几何曲率）；
- **CC-RRT / RRT 圆弧扩展**：文献里对“曲率连续扩展”的成熟做法，可对照；
- **Hybrid A\* / State Lattice**：把 (x,y,θ) 离散化 + 预生成运动原语网格搜索。它更“彻底”但状态离散化开销大；我们的场景（100 m 开阔水域、稀疏障碍、终点少）更适合**连续采样的姿态 RRT**。若将来要**确定性、有上界时间**的规划（比赛/评审），可再评估 lattice/Hybrid A*。

## 5. 性能、难点与缓解

| 难点 | 表现 | 缓解 |
|---|---|---|
| 有界曲率扩展成功率低 | 大量采样被拒(方向太偏) | 采样时限制 θ/方位角锥；目标偏置；必要时“直行优先” |
| 航向收敛慢(θ 是连续的) | 后期难精确对准目标 | 目标偏置 + 终点 Dubins 精确连接 |
| 港内窄(5m)随机采样低效 | 树难钻进港 | 口部走廊引导采样(性能优化)；墙体层 clearance 别太严 |
| 圆弧碰撞检查贵 | 每边多点判距 | 弧长步长 0.25~0.5m；先用包围盒/圆粗筛 |
| 迭代次数/耗时 | 比 2D 慢 | 可接受目标:单世界 <60~120s；首解后 informed 采样 |

## 6. 验收标准（实现后用它自测）

- 布局集：seed 5555、999999、1949237768 + ≥10 组随机布局；
- 指标：
  1. **首次尝试成功率**（不靠 attempts 重试）尽量高；
  2. 全程 `κ ≤ 1/R_min`（R_min 默认 5 m），由构造保证 + 报告复核；
  3. 终点姿态满足容差（位置 ≤1 m、航向误差 ≤10°，或 Dubins 精确）；
  4. 入港口部状态（航向/横向）落库的可行区（顺带验证无“斜不进去”矛盾）；
  5. 单世界耗时目标（先争取 < 2 分钟）；
  6. 输出与现有 JSON/图/CSV 字段兼容（中心线/走廊/曲率/口部指标，新增每段 primitive）。

## 7. 需要先定的小决策（实现前）

1. 目标姿态容差 vs 精确 Dubins 连接（推荐：先容差快速解，再精确连）；
2. cost 只用弧长，还是“弧长 + λ·累计转角”（推荐先只弧长，简单）；
3. 开阔障碍 clearance：用 `hw`(=1.5) 即可，还是要留 0.3~0.5 缓冲（推荐 hw+0.3，兼顾可执行与窄缝通过）；
4. 是否保留旧 2D 代码为 `--align` 对照（建议保留，成本低）；
5. 港前引导采样是否先做（先不加，验证纯随机姿态 RRT 的成功率再决定）。
